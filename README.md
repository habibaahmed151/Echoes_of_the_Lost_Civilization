# Echoes of the Lost Civilization

A Python/Pygame game where the player explores an ancient temple, collects keys, opens locked doors, solves puzzles, avoids traps, and finds treasure. An AI agent can also solve the temple using BFS, DFS and A*, and the game compares their performance.
